# Use of artificial intelligence

Use of AI. AI assistants (Claude, Anthropic) were used to write and debug most of the processing code, draft documentation, web text and slides, and review outputs, from the author’s specifications. The author chose the question, study area, data and validation strategy; ran every script on his own machine; inspected the outputs and flagged problems (e.g. the 2 Sep optical gap and classification noise in the river channel); required literature support before adopting methods; and made all final decisions. No data, labels or results were generated by AI. Every code file carries an “AI-assisted” header.

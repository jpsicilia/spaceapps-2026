# Use of artificial intelligence

This project was built by one person (José Pablo Pérez Cicilia) during the hackathon (14–15 Nov 2026) with the help
of **two separate AI chat sessions**, used in different roles. The author approved every change, relayed instructions
between the two sessions and ran all the code on his own machine.

## 1. Coding assistant (Claude, Anthropic)
- **Code.** Wrote most of the processing code in `scripts/` and `src/` (preprocessing, masks, classification,
  validation against DSWx-HLS and the river gauge, the tests, the web export, the web page, the document and slide
  builder) from the author's specifications, and fixed it from the terminal output the author pasted back. It did not
  run the pipeline on the real data.
- **Text.** Drafted the README Results wording, the web page text, the demo slides and script, the submission draft
  and this documentation. Numeric content is generated from the result tables, not typed by hand.
- **Checks.** Flagged some problems in outputs (for example that the 2 Sep optical gap could not be explained by
  cloud, and wording that had not been measured) and looked up citations and product documentation on the web.

## 2. Independent reviewer (Claude, Anthropic — a separate chat session)
- Audited the outputs, the repository and the published page without access to the coding session.
- Proposed most of the scientific corrections: calibrating the water thresholds on the JRC permanent-water zone
  instead of Otsu, the interpretation of the July→August drop (vegetation emerging over shallow water), the coverage
  interpretation for 2 Sep (a missing HLS/DSWx tile, not cloud), the 24-day gap, and the acceptance criteria of the
  tests (wind check, July→August loss test, partial-water classifier), which were fixed before each test was run.

## What the author did
- Chose the question, study area, data, validation strategy and the hackathon scope.
- Decided which suggestions from either session to accept, relayed them, and rejected or corrected others.
- Ran every script on his own machine, reviewed the outputs and the published web page, audited the published
  numbers against the result tables (`docs/claims.md`), and approved every text before publishing.

## What the AI did not do
- No data, labels, images or results were generated by AI: all maps and numbers come from NISAR, OPERA DSWx-HLS,
  Copernicus DEM, JRC, OpenStreetMap and ANA data processed by the code in this repository.
- No AI model is part of the scientific method. The only machine-learning model (a gradient-boosting classifier in
  `02g_partial_clf.py`) is a standard scikit-learn model trained on DSWx-HLS labels, and its pre-registered test failed.

All claims and their sources are listed in [`docs/claims.md`](claims.md).

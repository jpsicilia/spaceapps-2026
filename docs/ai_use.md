# Use of artificial intelligence

This project was built by one person (José Pablo Pérez Cicilia) with the help of an AI assistant,
**Claude (Anthropic)**, used through a chat interface during the hackathon (14–15 Nov 2026).

## What the AI did
- **Code.** Wrote most of the processing code in `scripts/` and `src/` (preprocessing, masks, classification,
  validation against DSWx-HLS and the river gauge, the pre-registered tests, the web export, the web page, the
  document and slide builder) from the author's specifications, and fixed it from the terminal output the author
  pasted back. The AI did not run the pipeline on the real data; the author ran every script on his machine.
- **Text.** Drafted the README Results wording, the web page text, the demo slides and script, the submission draft
  and this documentation. Numeric content is generated from the result tables, not typed by the AI.
- **Checks.** Pointed out problems found in the outputs (for example, that the first water threshold was separating
  forest from grassland, that a cloud explanation was not supported by the data, that some wording overstated the
  evidence) and looked up citations and product documentation on the web.

## What the author did
- Chose the question, study area, data and validation strategy, and the hackathon scope.
- Set the acceptance criteria before running the tests (wind check, July–August loss test, partial-water classifier),
  decided which results to keep, and rejected or corrected AI suggestions several times (water-threshold calibration
  on the JRC zone, the vegetation-emergence interpretation, the coverage wording, the 24-day gap).
- Reviewed every figure, number and text before publishing.

## What the AI did not do
- No data, labels, images or results were generated by AI: all maps and numbers come from NISAR, OPERA DSWx-HLS,
  Copernicus DEM, JRC, OpenStreetMap and ANA data processed by the code in this repository.
- No AI model is part of the scientific method. The only machine-learning model (a gradient-boosting classifier in
  `02g_partial_clf.py`) is a standard scikit-learn model trained on DSWx-HLS labels, and its test failed.

All claims and their sources are listed in [`docs/claims.md`](claims.md).
